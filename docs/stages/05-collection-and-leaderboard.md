# Stage 5: Collection And Leaderboard Workflows

## Goal

Make the collection and leaderboard feel complete once real scan data exists.

## Build Scope

- Show unlock date, matched confidence, and canonical swatch for every collected style.
- Add locked-state previews without revealing too much if the group wants discovery.
- Rank users by total unlocked styles, then latest unlock activity.
- Add all-eight completion state.
- Add empty, loading, error, and offline states for backend calls.

## Acceptance Criteria

- A user can understand what they have collected and what remains.
- Leaderboard updates after a successful scan.
- Duplicate scans do not create duplicate unlocks.
- Completed users have a distinct but restrained celebration state.

## Notes

Keep the interface fast enough to use while standing near Marco. The scan action should always be one tap away from the primary screens.
