# Marco Tracker

Marco Tracker is a mobile-first web app for collecting Marco's eight shirt colors. The current implementation has a local Node backend, account gate, progress display, collection view, leaderboard, and camera scanner flow with torch detection.

Run `npm start`, then open `http://localhost:3000` in a browser. The staged build plan lives in `docs/stages/`.

Camera scanning works best from `localhost` or an HTTPS URL. Phones usually require HTTPS before allowing camera access.
